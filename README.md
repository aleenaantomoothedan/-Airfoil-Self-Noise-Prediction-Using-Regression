# Airfoil Self-Noise Prediction Using Machine Learning Regression

## Project Overview

This project focuses on predicting the scaled sound pressure level generated by an airfoil using Machine Learning regression algorithms.

The Airfoil Self-Noise dataset contains 1,503 observations with five aerodynamic input features and one target variable.

The main objective is to understand the Machine Learning regression workflow and compare different algorithms to identify the best-performing model.

## Dataset Description

The dataset was obtained from the UCI Machine Learning Repository.

It contains the following features:

- Frequency
- Angle of Attack
- Chord Length
- Free Stream Velocity
- Suction Side Displacement Thickness

**Target Variable:** Scaled Sound Pressure

## Regression Algorithms Implemented

Six regression algorithms were implemented and compared:

1. Linear Regression
2. Polynomial Regression
3. Decision Tree Regression
4. Random Forest Regression
5. Support Vector Regression (SVR)
6. K-Nearest Neighbors Regression (KNN)

## Model Evaluation Metrics

The models were evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)

## Best Performing Model

Among the six algorithms, **Random Forest Regression** achieved the highest R² score of 93.46%.

It was selected as the best-performing model based on the evaluation results.
